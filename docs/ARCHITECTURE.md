# 实现结构与估计边界

## 数据流

`laserMapping.cpp` 保留原始点云—地图迭代滤波和 ikd-Tree。`src/fusion` 中的数学模块不依赖 ROS 消息；Runtime 管理 ROS2 输入、严格的时间顺序、观测去重和输出。

- 主估计线程消费有界 IMU/点云缓冲，辅助事件在自己的测量时刻插入 IMU 传播区间。同一时刻允许不同传感器分别更新。
- 去畸变使用滤波器副本及独立 IMU 轨迹；辅助更新不会倒写已经构造的去畸变轨迹。
- 独立 IO 线程处理高频 IMU 递推。校正后重放历史样本，版本和时间检查防止旧锚点覆盖新状态。
- 后端在独立工作线程消费有界事件队列。队列满时拒绝并计数，不无限堆积。

## 前端更新

原有 23 维误差状态顺序为位置、旋转、激光外参旋转、激光外参平移、速度、陀螺偏置、加速度偏置及二维重力切空间。新增辅助更新支持全状态雅可比。

相机克隆保留当前状态—历史位姿交叉协方差；IMU 传播应用同一个状态转移矩阵。激光更新后，使用条件分布传递克隆均值与协方差；状态注入后将协方差转换到新的误差切空间。视觉轨迹在结束或克隆窗口达到上限时形成结构消元观测，每段轨迹只消费一次。大量残差通过 QR 压缩后更新，避免求解巨大的像素空间创新矩阵。

视觉与轮速都使用同一个局部状态，不接收再次融合该 IMU 的独立 VIO 结果。外参采用离线标定。该实现没有额外声称满足严格的全局不可观性一致性证明，仍需真实数据与统计一致性评测。

## 退化与地图保护

对噪声白化和尺度归一化的六维激光位姿信息矩阵分析特征值，区分几何弱方向、匹配不足及异常残差。弱方向通过观测行空间投影削弱，残差和包括外参在内的雅可比一起投影，不提升特征值。没有约束的方向保留传播的不确定性。

进入和恢复采用按扫描计数的滞回，IEKF 的重复迭代不增加帧计数。严重失配期间冻结地图插入；恢复需要连续健康扫描。辅助观测仍接受各自的创新门限，不因为激光退化就自动信任其他传感器。

## 后端

iSAM2 图包含相邻局部位姿边、通过 Scan Context 和子图 ICP 验证的回环，以及后端模式下的轮速、天线位置和结构消元双目因子。图像节点使用真实图像时刻；同一时刻的激光校正会替换对应局部位姿边，避免使用旧的预测位姿。

不再次添加同源 IMU 预积分因子。LIO 相邻状态具有时间相关性；目前相对边协方差由边际近似并保守膨胀，不能视为严格独立的相对协方差。回环检查描述子距离、配准收敛、残差、重叠及相对运动修正幅度，并使用鲁棒核。

候选检索先排除超过“最大回环平移 + 最大允许修正”距离的位姿，再比较描述子，避免遥远的重复场景遮住附近有效候选；这也限制了可纠正的漂移范围。单元测试覆盖实际加入回环和重复场景候选选择，真实回放是否触发回环另外报告。

Scan Context 比较当前扇区 j 与历史扇区 j+shift，故从当前点云到历史点云的 ICP 初始航向使用正 shift。90° 重访回归测试记录了错误符号下的失败和修正后的通过。

视觉因子在轨迹结束时消去三维点，不向图添加无限增长的显式地标。全局位姿和关键帧仍随路线增长；长时间运行的全局地图存储不是固定内存实现。

后端结果只改变 map→odom 和全局产物。前端模式中，图的局部边已经包含辅助融合结果，不再加入原始辅助因子。后端模式中，辅助因子不修改局部状态。诊断同时给出路由计数与实际后端因子数量，便于检查互斥行为。

里程计发布前完成协方差赋值和 base_link 杆臂变换；角速度及杆臂速度包含陀螺测量噪声。全局消息的 pose 使用图边际，twist 保留局部速度边际，两者分别发布，不拼接未经建模的交叉协方差。

## 跨会话固定地图定位

`localization.enabled=true` 时，Runtime 用独立定位线程替代建图后端，只由定位模块发布 map→odom。前端仍构建自己的 odom 局部地图，历史地图只读。严重前端匹配失败的扫描仍交给定位模块独立验证；前端地图插入保护不变。

地图包的 manifest.txt 使用 `FASTLIO_MAP 1` 标识版本，随后记录不可变 generation 目录名、关键帧数量，以及各帧的 `id timestamp tx ty tz qx qy qz qw points`。位姿是 map_T_imu，关键帧 PCD 是 IMU 系点云。保存先完成 generation 目录，最后原子替换 manifest.txt；旧 generation 保留，读取不会混合不同次保存的数据。此提交保证文件可见性，不承诺断电后的磁盘持久性。

重定位复用回环的 Scan Context 描述子和正航向 shift 约定，检索前 K 个候选，不使用 odom 位置过滤。ICP 验证重叠、内点均方距离及目标邻域法线形成的信息矩阵；近似平面或直线等不可观测场景不能独立建立全局定位。候选中相距较远且配准得分接近的结果被视为歧义；比较同时使用相对比例和绝对均方距离余量，避免体素量化误差使相同场景的一个副本被误判为明确胜出。连续多帧确认后才发布全局结果；跟踪只搜索预测位置附近地图，并限制单次修正。失败扫描暂停发布，连续失败达到门限后重新全局检索。

工作队列只保留最新一帧，避免定位耗时拖慢 LIO。会话重置和手动初始位姿使用递增版本号，使正在计算的旧结果无法发布。已加载地图保留。定位结果中的位姿协方差来自点到面残差的局部线性化近似，包含平移和旋转耦合；它没有建模历史地图不确定性、相关观测或候选选择错误，不能作为严格全局置信区间。速度沿用 LIO 的局部边际。
